# Brand assets — सरस्वती नगरी (Saraswati Nagri)

Drop the source brand images here with these exact names:

| File | What it is | Used for |
|------|-----------|----------|
| `logo.png` | Circular लोगो (square) | Login page, sidebar, PWA icons (192/512), apple-touch-icon, favicon |
| `wallpaper-mobile.png` | Portrait aerial render | Login background on phones (PWA) |
| `wallpaper-desktop.png` | Landscape aerial render | Login background on tablet/desktop |

PWA icons are generated from `logo.png` (macOS `sips` or `sharp`), so only the
source files above need to be added by hand.
